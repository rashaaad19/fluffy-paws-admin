# Fluffy Paws Admin App (React Native)

> **Training project.** This repository is the admin mobile app of **Fluffy Paws**, the team graduation project of the *Frontend and Mobile Cross-Platform Training* at the **Information Technology Institute (ITI), Port Said** (03/2025 – 08/2025). It is not a production application.

The admin app of the Fluffy Paws pet boarding and hospitality platform, built with **React Native**. Admins use it to review and authorize newly created accounts.

## Related Repository

- Fluffy Paws website and backend: [fluffy-paws-app](https://github.com/IbrahimOraby/fluffy-paws-app) ([live demo](https://fluffy-paws-app.web.app/))

## Getting Started

```bash
git clone https://github.com/rashaaad19/fluffy-paws-admin.git
cd fluffy-paws-admin
npm install
npm start   # confirm the start command in package.json
```

> The app talks to the Fluffy Paws backend. Configure the API URL as described in the code.
